# daniels_search_engine
Daniel Search Engine is a lightweight web-based search engine built with HTML, CSS, and JavaScript.
It provides a simple interface for entering queries, displays results dynamically, and demonstrates core search engine concepts like indexing and keyword matching. Perfect for learning front‑end development and how search engines work at a basic level.

## 🚀 Features
- Built entirely with HTML, CSS, and JavaScript
- Simple search bar interface
- Dynamic display of search results
- Responsive design for desktop and mobile
- Easy to customize and extend
